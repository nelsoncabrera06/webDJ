# Investigaciones

Notas tipo wiki sobre los conceptos detrás de este mixer DJ: teoría musical,
audio y procesamiento de señales, explicados de forma accesible. La idea es
entender **cómo funcionan las cosas**, más allá del código.

## Índice

  (igualar velocidad, alinear los golpes, el PLL y la detección de BPM/beatgrid).
